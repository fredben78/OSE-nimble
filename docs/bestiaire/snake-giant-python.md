# Snake—Giant Python (Serpent—Python Géant)

## Description
Serpents de 6 m de long, aux motifs en spirale brun et jaune sur leurs écailles. Émergent de crevasses inconnues durant l'unesaison Chame (voir *Seasons and Unseasons*, DCB).

## Conversion Nimble

> **PYTHON GÉANT** LVL 5, Grand — ♥58, Sans armure
> *Constriction : sur une morsure réussie, le python s'enroule autour de la victime — elle subit ensuite automatiquement 2d4 dégâts chaque round tant qu'elle ne s'est pas libérée (Épreuve de FOR pour s'échapper).*
> **Morsure.** 1d10+13 (Contact).

**Moral (note narrative)** : Moral moyen (8) — chasseur patient qui n'apparaît que durant l'unesaison Chame ; une fois enroulé autour d'une proie, il ne relâche que si elle se libère ou meurt.

## Notes de lore additionnelles
Ce python n'émerge que durant l'unesaison Chame, l'une des saisons instables du Dolmenwood — une piste narrative intéressante pour lier sa rencontre à un moment calendaire précis plutôt qu'à un lieu fixe.

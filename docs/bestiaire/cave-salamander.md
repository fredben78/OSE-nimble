# Salamandre des Cavernes

## Description
Amphibiens souterrains carnivores de 1,5 m, qui émergent parfois à la surface la nuit. Peau bleu foncé tachetée d'orange. Agressives mais facilement effrayées.

## Statistiques Dolmenwood (source)
Medium Animal — Animal Intelligence — Neutral. Level 3, AC 14, HD 3d8 (13 PV), Att Morsure (+2, 1d8), Speed 40, Morale 6, XP 40, Enc 1d6.

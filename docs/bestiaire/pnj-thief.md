# Thief (PNJ générique)

## Description
Voleurs rencontrés dans les terres sauvages — souvent des bandits ou des pirates organisés en bandes.

## Statistiques Dolmenwood (source)
**Level 1 Thief (Footpad)** — AC 12, HP 1d4 (2), Speed 30, Morale 7, XP 15, Enc 3d10.
Gear : armure de cuir, épée longue (1d8), 3 dagues (1d4). Back-stab : +4 attaque, 3d4 dégâts. Skills : Climb Walls 4, Decipher Documents 6, Disarm Traps 6, Legerdemain 6, Listen 6, Pick Locks 5, Search 6, Stealth 5.

**Level 3 Thief (Robber)** — AC 14, HP 3d4 (7), Att +1, Speed 30, Morale 8, XP 65, Enc 1d6.
Gear : *Fairy Leather Armour*, épée longue, 3 dagues en argent (1d4), *Vanishing Philtre*. Back-stab : +4 attaque, 3d4 dégâts. Companions : 1d6 footpads.

**Level 5 Thief (Leader)** — AC 14, HP 5d4 (12), Att +2, Speed 30, Morale 9, XP 360, Enc 1.
Gear : *Fairy Leather Armour*, *Arcane Shortsword* (1d6+2, +2 attaque), 3 dagues en argent, *Liquid Time*, *Orgon's Scintillating Philtre*. Back-stab : +4 attaque, 3d4 dégâts. Companions : 1d4 robbers, 2d6 footpads.

## Notes
- Équipement typique : armure légère, arme légère, dagues de jet, quelques flacons magiques mineurs.
- Correspond aux bandits/pirates rencontrés en groupe dans les terres sauvages plutôt qu'aux voleurs urbains.
- Utilisable comme chef de bandits sur la route, contact de guilde, ou rival de crime organisé.

# Têtorisson

## Description
Hérissons aux piquants noirs, infestés de puces, avec de longues langues roses qui leur servent à attraper les insectes. Sortent des sous-bois pour dormir sur la tête des campeurs, les infestant de puces et leur léchant les oreilles de leur langue fouineuse. Fuient quand ils sont découverts.

## Statistiques Dolmenwood (source)
Small Animal — Animal Intelligence — Neutral. Level 1, AC 12, HD 1d4 (2 PV), Att Morsure (+0, 1d2), Speed 30, Morale 6, XP 10, Enc 2d6.

# Faucon

## Description
Petits oiseaux de proie, parfois dressés comme gardiens ou pour la chasse. N'attaquent les humanoïdes que s'ils semblent sans défense.

## Statistiques Dolmenwood (source)
Small Animal — Animal Intelligence — Neutral. Level 1, AC 11, HD 1d4 (2 PV), Att Serre (+0, 1d2), Vol 160, Morale 7, XP 15, Enc 1d6.

## Conversion Nimble

> **FAUCON** LVL 1, Petit — ♥26
> *Piqué. Fond en piqué sur une victime visible depuis les airs. Si la victime est Surprise, les dégâts sont doublés.*
> **Serres.** 2d10 (Reach 1).

**Moral (note narrative)** : N'attaque que des cibles semblant sans défense ; se retire si la situation se complique.

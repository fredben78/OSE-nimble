# Crier (PNJ générique — Everyday Mortal)

## Description
Officiels flamboyamment habillés qui portent les nouvelles aux villages, parfois accompagnés de souffleurs de fanfare. Généralement humains ou breggles.

## Conversion Nimble

> **CRIEUR** LVL 1/4 — ♥12
> **Gourdin, dague ou bâton.** 1d4+1

**Moral (note narrative)** : Morale 6 — ne se bat jamais ; sa priorité est de délivrer son message puis de partir vers la prochaine localité.

## Notes
- Niveau estimé à 1/4 : PNJ purement narratif, aucune vocation martiale.
- Équipement typique : tenue voyante, parchemin officiel, parfois une cloche ou un cor de fanfare.
- Usage MJ : outil pratique pour relayer un hook d'aventure ou un événement de campagne (table Nouvelles ci-dessus) sans détour par un dialogue improvisé.

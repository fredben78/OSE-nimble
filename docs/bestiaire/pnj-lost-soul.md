# Lost Soul (PNJ générique — Everyday Mortal)

## Description
Individus désorientés, totalement inconscients de l'endroit où ils se trouvent, essayant de retrouver le chemin de chez eux.

## Conversion Nimble

> **ÂME PERDUE** LVL 1/4 — ♥12
> **Gourdin, dague ou bâton.** 1d4+1

**Moral (note narrative)** : Morale 6 — totalement inoffensive ; ne se bat jamais, cherche seulement de l'aide ou des indications.

## Notes
- Niveau estimé à 1/4 : PNJ non-combattant, potentiellement source de quête (aide à ramener chez soi).
- Peut porter un indice temporel ou géographique fort (voir table Destin) qui accroche une intrigue plus large (voyage temporel, Féerie, morts-vivants).
- Usage MJ : excellent déclencheur d'aventure — le foyer et le destin tirés indiquent où et pourquoi ramener le PNJ.

# Crabe Géant

## Description
Crustacés voraces de 1,2 m, engendrés dans les eaux étranges du lac Longmere. Se cachent dans les hauts-fonds et rampent le long des plages. Attaquent voracement toute créature en mouvement.

## Conversion Nimble

> **CRABE GÉANT** LVL 3 — ♥33, Armure Moyenne
> **Pinces.** 2d10+4 (Reach 1).

**Moral (note narrative)** : Attaque voracement tout mouvement à proximité, sans grande discipline ni retenue.

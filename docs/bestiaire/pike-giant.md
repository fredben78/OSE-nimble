# Pike, Giant (Brochet Géant)

## Description
Poissons prédateurs de 2,70 à 4,25 m de long. Attaquent tout ce qui passe à proximité lorsqu'ils ont faim. Se reproduisent dans les profondeurs du Groaning Loch, mais nagent parfois dans d'autres lacs et rivières.

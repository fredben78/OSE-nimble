# Scarabée de Feu Géant

## Description
Scarabées de 60 à 90 cm dotés de trois glandes luminescentes sur leur carapace irisée (une au-dessus de chaque œil, une sur l'abdomen). Se cachent dans les cavernes et clairières sombres, se nourrissant de champignons et de mousses. Pacifiques sauf pour défendre leur nid.

## Conversion Nimble

> **SCARABÉE DE FEU GÉANT** LVL 1, Petit — ♥20, Armure Moyenne
> *Nodules lumineux. Émettent une lumière dans un rayon de 3m. Si retirés du scarabée, ils continuent de briller pendant 1d6 jours — une source de lumière portable prisée des explorateurs.*
> **Morsure.** 2d6+4 (Reach 1).

**Moral (note narrative)** : Pacifique sauf pour défendre son nid ; se bat alors avec une détermination modérée.

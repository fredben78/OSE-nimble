# Mentions légales

## Statut de ce site

Ce site présente un aide-mémoire des règles du système de jeu de rôle **Nimble**, sans contenu tiré d'un setting ou d'un supplément tiers. Il n'est ni affilié à, ni approuvé par **Nimble Co.**, éditeur de *Nimble*.

**Soutenez le jeu officiel** : procurez-vous les livres *Nimble* (Core Rules, Heroes, GM's Guide) sur [nimblerpg.com](https://nimblerpg.com).
